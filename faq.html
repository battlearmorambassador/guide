FAQ

General

Can I get banned for any of this?

No. You're not playing the latest version here. You're not connecting to the live servers. As such, no one ever got banned for doing any of this.

How can I play on the latest version?

We are one version behind as this is a preservation project. Discussion about modifying versions beyond the latest supported is banned both from git and Discord.

How come I see my email/warframe on the login screen?

You may see your email address and appearance from live servers on the login screen for your local server and vice-versa. This is because all versions/installations of Warframe use the same cache for this. This cache never leaves your computer.

Are DE aware of this? Are they okay with this?

They are likely at least partially aware of this project. How they feel about it is unclear, and that's not for a lack of trying to get a response.

Can I play with friends?

Yes. The person hosting sets up the server and makes it reachable, e.g. with Port Forwarding. Everyone else only needs the same game version and the Client Setup, with the host's address as server_host. To be in the same squad, the host also needs to configure NRS.

Troubleshooting

I can't log in. What should I check?
  • The server window is still open and shows no errors.
  • http://localhost/ opens the SpaceNinjaServer WebUI (if the server runs on your computer).
  • server_host in OpenWF/Client Config.json is the right address (127.0.0.1 for a server on your computer).
  • OpenWF/Client Config.json is still valid JSON after your edits (quotes and commas intact). You can check it with this JSON validator.
  • You're using the same email and password as when the account was created.
"git" or "npm" is not recognized as a command

Make sure Git and Node.js are installed (see the prerequisites), then close the command prompt and open a new one. A command prompt that was already open before the installation doesn't know about them yet.

The server won't start because port 80 or 443 is already in use

Another program (e.g. another web server) is using that port. Either close that program, or change httpPort/httpsPort in SpaceNinjaServer's config.json and set the same values as http_port/https_port in OpenWF/Client Config.json.

My files ended up in C:\Windows\System32

This happens when commands are run from a command prompt opened via the Start menu, which starts in C:\Windows\System32. Move the downloaded folder (e.g. SpaceNinjaServer) somewhere else, such as your Desktop. Next time, open the command prompt in a dedicated folder: in File Explorer, type cmd in the address bar and press Enter.
