OpenWF is a community project that aims at preserving Warframe and playing offline.

Prerequisites

Before proceeding with the guide, make sure to have the following software installed on your machine:

  • Git
  • Node.js

Mandatory. The following steps will not work without them.

Must know

  • SpaceNinjaServer is your local server where all gets redirected to.
  • WebUI is your server's interface, where you can manage your inventory and enable cheats.
  • Client is whatever refers to the bootstrapper and subsequent folders, located next to the game's executable file.
  • localhost:6155 is the interface that interacts directly with the bootstrapper, notably for script execution, metadata parsing and custom tweaks.
