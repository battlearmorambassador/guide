Server Setup

All commands below must be typed in a command prompt (cmd) or terminal, not in the File Explorer or a browser. The command prompt has to be opened in a dedicated folder (e.g. on your Desktop or another drive), not in C:\Windows\System32, which is where it starts when opened from the Start menu. On Windows, the easiest way is to open the folder in File Explorer, type cmd in the address bar and press Enter.

Steps

  • Run this in your command prompt to download SpaceNinjaServer into a new SpaceNinjaServer folder inside the current folder:
    git clone https://openwf.io/SpaceNinjaServer.git
  • Open the SpaceNinjaServer folder:
    cd SpaceNinjaServer
  • Copy config-vanilla.json to create a config.json:
    • Windows:
      copy config-vanilla.json config.json
    • Linux:
      cp config-vanilla.json config.json
  • (Optional) If you have a GB of free space, you might want to download stripped assets such as ability videos so the client can request them on-demand:
    cd static/data && git clone https://openwf.io/stripped-assets.git && cd ../..
  • Install library dependencies:
    npm install --omit=dev --omit=optional
  • Now you can start the server anytime with:
    npm run raw

Linux note: OpenWF software uses ports 80 and 443 by default, which require root/su permissions to bind.

First login

  • Start the server (using UPDATE AND START SERVER.bat or in a cmd window with npm run raw) and leave its window open for as long as you play. To check that it's running, open http://localhost/ in your browser: you should see the WebUI.
  • Start the game with the Launch with OpenWF script from your game folder (see Client Setup).
  • On U33 and newer, the top-left corner of the login screen shows OpenWF @ 127.0.0.1 (or whatever your server_host is). If a warning appears underneath it, the game can't reach the server: check that the server window is still open and that server_host is correct.
  • Enter any email address and password and log in. The first time, an account is created with them automatically. Use the same email and password every time after that.

That's it: you're playing on your own server. These guides are optional extras: Importing your live account, Chat & Hubs and Multiplayer.

Usage

With the server running, you can obviously connect to it with a patched Warframe installation.

When logging in with an email address that has no associated account, it will automatically be created (autoCreateAccount in config.json). If you want newly-created accounts to be past the tutorial, set skipTutorial to true in the config.json.

Furthermore, SpaceNinjaServer has a WebUI that you can access at http://localhost/ where you can view and edit your savedata, as well as modify the server's config.

Updating your server

SpaceNinjaServer is constantly updated with new features and bug fixes, which is why it comes with an UPDATE AND START SERVER script.
