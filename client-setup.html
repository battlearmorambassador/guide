Client Setup

  • Download Bootstrapper Setup (Linux version).
    Source code
  • Move it next to the game's executable and double click on it, then delete Bootstrapper Setup from this folder.

Config

  • To start the game, run the Launch with OpenWF script.

    • This won't let you log in unless your OpenWF/Client Config.json is valid and you have completed the Server Setup.

      OpenWF/Client Config.json gives you many options, such as the fallback language and graphics driver. Check the Templates & verifier page to learn more.
  • While the game is running, you can visit http://localhost:6155/ to access Bootstrapper features like scripts.
  • To join a server that isn't running on your computer, set server_host in OpenWF/Client Config.json to its address.

For more information, check out the Bootstrapper's comprehensive manual, which you can also find in the OpenWF/Reference Manual.html file.
